### 🚀 Featured Project

#### 💼 WorkBridge — Job Marketplace & Freelance Platform

A complete job marketplace platform built three times across three stacks, all sharing the same Spring Boot REST API.

**Tech Stack:** `Spring Boot` · `Angular` · `Flutter` · `Android (Java)` · `MySQL` · `JWT` · `Spring Security` · `Hibernate/JPA`

**Includes:**
- Job postings, gig orders, wallets & payments
- Real-time messaging and reviews
- AI-assisted resume import & AI interviews
- PDF/Excel export
- Companion native Android app + Flutter app (Android, iOS, Web) sharing the same backend
